# 学校已有账号接入

学生使用学校原账号（如 `xjy900`）和原密码登录网站，不注册新账号，也不绑定微信。独立工作人员账号由管理员发放；学校账号取得审核权限后仍沿用学校原密码。

## 当前实现

`cloudfunctions/study/school-auth.js` 是认证适配层，当前仅验证本项目测试记录中的scrypt摘要。未知账号不能登录，也不会自动创建账号。真实学校数据库、账号查询、状态同步和密码校验尚未接通。

密码不写日志、不返回客户端、不保存到浏览器缓存。网页会话放在HttpOnly Cookie中。管理员不能通过本站重置学校原密码；工作人员独立账号可修改或重置密码。

学校账号标记为 `enrollmentStatus: inactive` 后，新登录和旧会话都会被拒绝。账号ID保持稳定，姓名、角色或密码变化不重建额度和处罚。

## 等待学校提供

1. 账号密码验证接口，或授权的数据导出/只读数据库连接。如有接口，优先让学校原系统验证密码。
2. 账号唯一标识、字段名、大小写规则，姓名与启用状态字段。
3. 仅能接数据库时，密码校验算法、盐和摘要格式说明；不要提供明文密码清单，也不能将未知格式摘要直接当作scrypt导入。
4. 账号停用、密码变更或离校时的状态同步方式和会话撤销要求。

收到字段说明或脱敏样例后实现适配。管理员页面的学生录入仅用于测试。

历史微信绑定和二维码登录已封存在 `archives/wechat-2026-10-20/`；当前不使用这些字段、入口或票据，也不会删除历史业务记录。
