# 处罚与预约额度规则

本文件记录本次讨论确定的实现。所有时间均按北京时间（UTC+8）；天表示连续24小时。

## 账号与预约

学生使用学校已有账号（如xjy900）和原密码登录网站。预约、额度、处罚和首次警告记录归属于原账号。学校原账号密码由学校原系统管理。

学生账号默认每个自然周600分钟额度，每周一00:00进入新一周。预约按实际使用日期所属周扣除，提前预约下周不占本周额度。最低单位30分钟，开始和结束均需落在整点或半点。

只有学生账号可预约和提交举报。审核员仅能查看、审核举报；管理员可增加座位、接入学生账号及发放审核账号、调整权限、重置工作人员密码、查看和取消预约、登记独立违规。授予审核权限会取消该账号未开始的学生预约，退出审核权限不会清除处罚历史。学校账号获得审核权限后仍使用原账号和密码登录。

未开始预约取消后释放座位并退回原周时长。预约一旦开始，不能取消或退时长。所有学生的同一时间段只能占用一个座位。

## 等级与扣时

| 新处罚等级 | 封禁预约权限 | 处罚当周扣除 | 下一周扣除 |
|---|---|---|---|
| 0级，首次警告 | 1天 | 5小时 | 无 |
| 1级 | 3天 | 6小时 | 无 |
| 2级 | 7天 | 10小时 | 5小时 |
| 3级 | 永久 | 无额外扣时，预约已永久禁止 | 无额外扣时 |

处罚以审核通过时间（手动处罚以管理员提交时间）为起点，不按举报提交时间追溯。封禁禁止申请任何新预约，即使所选使用时间在解封之后。

每次处罚先取消全部尚未开始的预约并退回对应周额度，再施加扣时。已开始或已结束预约不退款。剩余时长为 `max(0, 600 - 已用或已预约分钟 - 累计处罚扣除分钟)`；处罚可累计，不会出现负的可用时长。未规定跨周扣除的部分不会因当周额度不足而转移到下周。

二级中的“下周”是处罚发生后的下一个自然周，即使封禁时间覆盖这周，也仍按这个自然周扣除，不改为解封后的周。

## 升级与降级

- 从未受过处罚：使用唯一一次0级警告。
- 0级之后：最低从1级起算，0级机会不会因时间经过、密码重置、角色变更而恢复。
- 当前为1级：封禁期间或解封后不足7天再次发生独立成立违规，升为2级。
- 当前为2级：封禁期间或解封后不足30天再次发生独立成立违规，升为3级。
- 1级解封满7天无新处罚：降到基础状态，下次违规仍执行1级。
- 2级解封满30天无新处罚：降为1级；继续满7天无新处罚：降到基础状态。在这个中间7天内再犯，执行2级。
- 3级永久封禁不自动降级、不自动解除。
- 封禁期间发生新的独立成立违规，按上述等级继续升级；新的封禁从这次审核通过起算，不缩短原有封禁。

边界时刻采用“到点即降级”：例如1级于10月20日10:00解封，在10月27日09:59:59再犯升2级，在10月27日10:00再犯则执行1级。

二级示例：10月20日10:00解封，11月19日10:00降为1级，11月26日10:00降到基础状态。之前成立的0级警告永远保留“已使用”标记。

## 举报与审核

举报必须包含座位号、日期、30分钟对齐的起止时段、至少5字情况说明，以及1～3张现场照片。允许举报最近7天内已经发生或当前正在发生的时段。所选时段必须完整对应一条预约，不能跨两名预约者；系统由预约记录确定对象，普通学生看不到其他预约者身份。

审核员必须结合照片核实具体违规者和预约者是否为同一人。若照片只证明“有人占座”，不能据此认定预约学生违规。身份或事实无法确认时，应驳回并说明原因。

只有具备审核权限的账号可处理举报，且不能审核自己提交或针对自己的举报。通过和驳回均须填写至少5字意见。

同一预约最多形成一次自动处罚：同一举报不能重复审核；多名学生举报同一预约时，首次成立举报处罚，其余成立举报合并。若已经永久封禁，后续审核记录为“对象已永久封禁”，不再重复扣时。

管理员手动封禁用于经过现场核实的独立违规，同样按下一等级执行，并记录原因和操作人。网络重试使用相同操作标识，不会重复处罚。已有举报案件应通过举报审核入口处理，避免人工重复登记。
