# 自习之间 · 本地自习区预约网站

当前仅维护网站，使用学校已有账号（如 `xjy900`）和原密码登录。学生、审核员、管理员按账号权限访问预约、举报和管理功能。微信小程序、绑定和扫码登录已于2026-10-20封存，归档保留在原开发电脑，不上传仓库。

**当前默认本地运行，无需GPT登录。** 打开 `http://127.0.0.1:5173/`，使用本机配置的账号密码。双击 `启动网站.command` 或执行 `npm run local` 启动。详情见 [本地使用说明](docs/local-website.md)。

账号、预约和举报照片保存在本机 `.local-study/`，重启后保留。尚未接入学校真实数据库。旧托管配置保留供参考，本地版不加载Sites身份认证，也不依赖云函数运行环境。

## 功能

- 学校原账号密码登录；工作人员账号由管理员发放，首次须修改初始密码。
- 首页左上查看预约、左下举报、右侧预约座位。
- 管理员添加001起的连续座位，30分钟为预约单位，每周10小时。
- 未开始预约可取消，时长退回原周。管理员可查看和取消未开始预约。
- 举报必须提供照片、座位、日期、时间段及说明，由有审核权限的账号处理。
- 0～3级处罚、跨周扣时、到期解封和等级下降；同一预约只处罚一次。
- 审核账号发放、权限管理、独立违规处罚、工作人员密码重置及审计记录。

规则见 [处罚与额度](docs/rules.md)，数据接入见 [学校账号](docs/school-accounts.md)，网站部署见 [网站接入](docs/website.md)。

首次启动需按 [本地使用说明](docs/local-website.md) 配置初始账号，密码保存在忽略上传的本机文件中。

## 本地检查和运行

网站需要Node.js22.13以上。云函数与业务测试可用Node.js20以上。

```sh
npm ci --prefix cloudfunctions/study --ignore-scripts
npm test
npm run check
npm --prefix website run install:ci
npm run build:local
npm run local
```

网站已安装依赖时不必重复安装。打开运行命令输出的本地地址。网站类型检查：`cd website && npx tsc --noEmit`。归档目录不参与当前构建和检查。

## 旧云端部署参考（本地运行无需此步骤）

1. 准备云开发数据库和云函数运行环境。现有服务端SDK仅用于数据库、事务和证据存储，不调用微信身份或二维码接口。
2. 创建集合 `study_records`，客户端读写权限使用 `docs/database.rules.json`，存储权限使用 `docs/storage.rules.json`；读、写均为false，访问只能经过服务端鉴权。
3. 为集合添加非唯一索引：

   | 索引字段，按顺序 | 排序 |
   |---|---|
   | `_type`, `createdAt` | 升序、降序 |
   | `_type`, `ownerId`, `createdAt` | 升序、升序、降序 |
   | `_type`, `date`, `createdAt` | 升序、升序、降序 |
   | `_type`, `ownerId`, `date`, `createdAt` | 升序、升序、升序、降序 |
   | `_type`, `status`, `createdAt` | 升序、升序、降序 |
   | `_type`, `date` | 升序、升序 |


4. 部署 `cloudfunctions/study`，运行时Node.js18以上，建议60秒超时及256MB内存。按锁文件、`.npmrc`和vendor目录安装依赖。配置HTTPS入口及签名密钥，步骤见网站接入说明。
5. 服务端设置 `INITIAL_ADMIN_USERNAME` 和 `INITIAL_ADMIN_PASSWORD`。通过网站账号密码入口首次初始化管理员，随后必须修改密码，再移除初始化环境变量。无需经过小程序。
6. 管理员设置座位、开放时间和审核账号。真实学校账号等待数据源接入；学生手动录入仅用于测试。
7. 完成并发预约、额度、照片隔离、权限及处罚边界的实际环境验收后，再配置师生访问范围。

## 数据与实现边界

- 学校账号认证适配层目前只验证测试记录中的scrypt摘要；真实学校密码验证和账号状态同步仍待接入。
- 不自助注册未知学校账号；学校密码由原系统管理。
- 所有时长和处罚归学校账号ID。封存不会清除已有预约、额度、处罚或审计记录；历史微信字段保留但不再使用。
- 本次认证迁移让所有旧会话（含过去扫码签发的网页会话）失效，需重新输入账号密码。以后网页会话12小时过期，修改工作人员密码或调整角色后旧会话失效。
- 举报对应预约记录，审核须核实现场人员身份。无预约记录的事件由管理员核实后登记独立违规。
- 支持一个自习区，尚无多楼栋、签到、门禁、通知订阅或申诉流程。
- 到期解封、周额度更新和等级下降由服务端按时间计算，处罚扣时不会随解封返还。
- 照片每张700KB以内，每账号每天最多30张；证据保留和未关联上传清理需由学校确定运维周期。
- 列表每页30条，最大分页偏移10000。SDK替身测试不替代实际云数据库竞争、事务回滚和HTTP入口验收。
